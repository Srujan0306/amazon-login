# Sample README

A sample Markdown README that demonstrates common Markdown syntax and how to write it clearly.

## 1. Headings

Headings create structure.

# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6

## 2. Paragraphs and Line Breaks

A paragraph is one or more lines of text separated by one or more blank lines.

To add a line break within a paragraph, end a line with two spaces and press Enter.  
This is the next line.

## 3. Emphasis

*Italic text* or _italic text_

**Bold text** or __bold text__

***Bold italic text***

## 4. Lists

Unordered list:

- Item one
- Item two
  - Nested item
    - Deeper nested item

Ordered list:

1. First item
2. Second item
3. Third item

## 5. Links and Images

Link example: [GitHub](https://github.com)

Image example:

![Placeholder image](https://via.placeholder.com/150)

## 6. Inline Code and Code Blocks

Inline code: `npm install`

Fenced code block:

```bash
npm install
npm run start
```

Indented code block:

    def hello_world():
        print("Hello, Markdown!")

## 7. Tables

| Feature       | Description                 |
|--------------|-----------------------------|
| Headings     | Use `#` symbols             |
| Lists        | Unordered and ordered lists |
| Code blocks  | Use backticks or indentation |

## 8. Blockquotes

> This is a blockquote. Use `>` at the beginning of the line.
>
> Blockquotes can span multiple lines.

## 9. Task Lists

- [x] Completed task
- [ ] Pending task
- [ ] Another task

## 10. Horizontal Rules

Use three or more hyphens, asterisks, or underscores:

---

***

___

## 11. Miscellaneous

- Emoji: :smile:
- HTML tags are allowed in Markdown: <kbd>Ctrl</kbd> + <kbd>C</kbd>

## 12. Tips for Writing Markdown

- Keep headings concise.
- Use blank lines to separate paragraphs and sections.
- Use code blocks for commands and examples.
- Preview your Markdown to verify formatting.
